## 这套文档解决什么

把照片、影音、笔记、下载任务搬到自家机器上，难点从来不是「装上」，而是**半年后还管得住**。市面上的教程大多停在「跑起来了」，这份手册补的是后半段：怎么更新、怎么备份、出错时按什么顺序排查。

写给三类人：

- 有一台闲置机器或 NAS，想把服务搬回本地的普通用户
- 用过几年云服务、被流量费和停机坑过，想算清自托管划不划算的人
- 帮家里或小团队搭环境，需要一份别人也能照着做的手册的人

## 能放些什么

| 用途 | 例子 | 值得自己托管吗 |
| --- | --- | --- |
| 📷 照片与相册 | 相册去重、按年归档、外网可看 | 值得，数据在你手里 |
| 🎬 影音库 | 转码、刮削、局域网串流 | 值得，前提是家里带宽够 |
| 📝 笔记与文档 | Markdown 双向同步 | 值得 |
| 🔒 密码管理器 | 主密码库 + 自动填充 | 值得，但必须先想清楚备份 |
| ☁️ 网盘同步 | 大文件双向同步 | 谨慎，同步冲突很难处理 |
| 💬 即时通讯 | 私有化聊天服务 | 一般，客户端维护成本高 |
| 🎮 游戏服务器 | 小规模联机 | 视延迟要求而定 |
