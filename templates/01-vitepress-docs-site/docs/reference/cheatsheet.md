## 一个够用的排查顺序

<!-- 类型：把所有诊断命令串成一条可复制的流水线。这是最常被单独复制的部分。 -->

遇到任何问题，按这个顺序走，**不要跳步**：

```bash
# 1. 【看状态】
# 2. 【看日志——90% 的原因在这里】
# 3. 【配置能否解析】
# 4. 【依赖是否正常】
# 5. 【资源是否耗尽】
# 6. 【系统层错误】
```

**第 2 步通常就够了。** 如果日志里什么都没有，再往下一步走。
